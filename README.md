# GTA 6 News Bot

Бот сам собирает всё про GTA 6 и публикует в Telegram-канал:

| Что | Откуда |
|---|---|
| ⭐️ Официальное (трейлеры, обновления, анонсы) | YouTube Rockstar Games |
| 📰 Новости и 🕵️ слухи/утечки | Google Новости (RU + EN), Rockstar Intel, Insider Gaming, VGC, IGN, GameSpot, PC Gamer, Eurogamer, StopGame, PlayGround.ru |
| 📘 Гайды и ⚙️ настройки | отдельные поиски Google News по «guide / tips / best settings / гайд / настройки» |
| 💬 Сообщество | топ постов дня в r/GTA6 |
| 🔴 Начало крупных стримов | Twitch (категория GTA VI, от 3000 зрителей + ваш список стримеров) |

Посты автоматически получают хэштеги (`#GTA6 #новости #гайд #настройки #обновление #трейлер #слухи #стрим #видео`), английские заголовки переводятся на русский, дубли одной новости с разных сайтов отсекаются.

## Запуск за 10 минут

### 1. Канал и бот
1. В Telegram создайте **канал** (публичный, например `@gta6_news_ru`).
2. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
3. Добавьте бота в **администраторы канала** с правом «Публикация сообщений».

### 2. Twitch (для уведомлений о стримах, необязательно)
1. Зайдите на https://dev.twitch.tv/console/apps → **Register Your Application**.
2. OAuth Redirect URL: `http://localhost`, Category: `Other`, Client Type: `Confidential`.
3. Скопируйте **Client ID** и создайте **Client Secret**.

### 3. GitHub (бесплатный хостинг)
1. Создайте **приватный** репозиторий и загрузите туда эту папку.
2. *Settings → Secrets and variables → Actions → New repository secret*, добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHANNEL` — `@имя_канала` (или числовой id `-100…` для приватного канала)
   - `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` — если нужны стримы
3. *Actions* → включите workflows → **GTA 6 news bot → Run workflow**.

Первый запуск **ничего не публикует** — он запоминает уже существующие новости, чтобы не завалить канал сотнями старых постов. Дальше бот запускается каждые 30 минут и публикует только новое (не больше 10 постов за раз, остальное — в следующий заход).

## Заявки на вступление
Бот сам одобряет заявки в канал и пишет новичку приветствие в личку (текст — `join_requests.welcome` в `config.yaml`).
Боту нужно право администратора «Добавление участников». На GitHub Actions заявка одобряется при ближайшем запуске (до ~30–45 мин), на VPS с `--loop` — мгновенно.

## Альтернатива: свой сервер / VPS
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHANNEL=@gta6_news_ru TWITCH_CLIENT_ID=... TWITCH_CLIENT_SECRET=...
python bot.py --loop 300     # проверка каждые 5 минут
```
Посмотреть, что бот опубликует, ничего не отправляя: `python bot.py --dry-run`.

## Настройка — `config.yaml`
- **Добавить источник**: любой RSS (`type: rss`) или YouTube-канал по нику (`type: youtube, handle: ...`). `filter: true` — пропускать только материалы, где упоминается GTA 6.
- **Стримы**: `min_viewers` — порог «крупного» стрима, `watchlist` — стримеры, о которых пишем всегда, `languages` — например `["ru", "en"]`.
- **Частота/объём**: `max_posts_per_run`, `max_age_hours`.
- **Перевод**: `translate.enabled: false`, если нужны оригинальные заголовки.

## Ограничения
- **X/Twitter** (где Rockstar и инсайдеры пишут первыми) не подключён: бесплатного API нет. Эти новости всё равно приходят через сайты и Google Новости с задержкой в минуты.
- **Kick и YouTube-стримы** пока не отслеживаются — только Twitch.
- GitHub Actions по расписанию иногда запускается с опозданием на 5–15 минут.
- Расписание — раз в 30 минут: в приватном репозитории бесплатно 2000 минут Actions в месяц, а каждый запуск округляется минимум до минуты. В **публичном** репозитории минуты не ограничены — там можно вернуть `*/10 * * * *` в `.github/workflows/bot.yml`. Если нужна мгновенная реакция — запускайте на VPS с `--loop`.
